# 需要手动检查的内容

冒烟测试通过 Pinta 自己的 API 驱动工具并渲染画布，覆盖了几何、绘制和屏幕上的结果。
它覆盖不了的是需要真实显示器、真实鼠标和真实安装的那部分。这份清单就是为那部分准备
的。

发版前在用户实际使用的 Pinta 上跑一遍——对大多数人来说是 Flatpak 版。

---

## 安装

- [ ] `.mpack` 能从 **插件 → 插件 → 从文件安装…** 安装。
- [ ] **Bezier** 工具出现在工具箱中 *Line/Curve* 的后面，图标正常，不是坏图。
- [ ] 选中工具后，菜单栏下方出现工具选项栏。
- [ ] 重启 Pinta 后工具仍然安装着。
- [ ] 用更新的 `.mpack` 覆盖旧版后，工具仍在工具箱里，并且还能画。
- [ ] 卸载后工具从工具箱消失，下次启动不崩溃。

## 画曲线

- [ ] 左键拖动用主色画线；右键拖动用副色。
- [ ] 第二次拖动放置第一个控制点，曲线向它弯曲。
- [ ] 第三次拖动放置第二个控制点，曲线完成。
- [ ] 按住鼠标时曲线跟随鼠标，不闪烁。
- [ ] **Enter** 完成曲线，标记消失。
- [ ] 右键单击完成三点曲线。
- [ ] 在别处拖动会完成当前曲线并开始下一条。
- [ ] **Esc** 取消正在画的曲线，图像保持原样。
- [ ] **Backspace** 撤回最后一个点；只剩两个端点时取消整条线。
- [ ] 方向键把高亮的点移动 1 像素，**Shift** 移动 10 像素。
- [ ] 切换到另一个工具会提交正在画的曲线。
- [ ] 切换到另一个文档会把曲线提交到它开始的那个文档，新文档不受影响。

## 标记

- [ ] 端点是蓝点，控制点是品红点，中间用虚线牵引线连接。
- [ ] 在 25%、100% 和 400% 缩放下标记大小一致。
- [ ] 悬停标记会高亮，光标变成抓取光标。
- [ ] 标记在浅色和深色图像上都看得见。

## 吸附

- [ ] 拖线时按 **Shift** 吸附到 0°、45°、90°，状态栏显示角度。
- [ ] **Ctrl** 吸附到 0°、30°、60°、90°。
- [ ] **Shift + Ctrl** 吸附到 0°、30°、45°、60°、90°。
- [ ] 放控制点时按 **Shift** 吸附到构造点：画布边缘和中心线、角点、线的中点与三等分
      点、已经放下的点，以及垂直平分线。
- [ ] 拖控制点时按 **Ctrl** 吸附到端点切线。
- [ ] 吸附感觉是选最近的允许角度，而不是下一个更大的角度。

## 工具选项栏

- [ ] 控件之间有间距，并且分组：笔宽、虚线、行为、提交、齿轮、拾起按钮。
- [ ] 每个框显示当前生效的选择。
- [ ] 提示文字可读，并且和窗口其余部分语言一致。
- [ ] 切换到别的工具再切回来，选择**保持不变**。
- [ ] **KolourPaint** 行为隐藏两个翻转按钮，显示提交框。
- [ ] **MS Paint** 行为显示翻转按钮，隐藏提交框。
- [ ] 没有对象在编辑时，翻转按钮是灰的。
- [ ] 还没提交过任何曲线时，拾起按钮是灰的。

## 样式面板

- [ ] 齿轮打开面板，切换工具时面板关闭。
- [ ] **起点 / 终点** 独立改变两端，预览能看出来。
- [ ] **连接** 改变尖角处的拐角。
- [ ] **渐变** 让描边从主色过渡到副色。
- [ ] **起点宽度 / 终点宽度** 让描边呈锥形；0 表示使用笔宽。
- [ ] **闭合曲线** 让曲线回到起点。
- [ ] **平滑接缝** 去掉闭合曲线接回自身处的拐角。
- [ ] **填充** 填充闭合曲线的内部。
- [ ] **对称：镜像** 画出对称的叶子；**中心** 画出对称的 S。
- [ ] 抓住派生出来的控制点会破坏对称。
- [ ] **整像素** 把每个点放到整像素上。
- [ ] 绘制时 **C** 和 **F** 切换闭合与填充。

## MS Paint 模式下的对象

- [ ] 完成的曲线带虚线框、八个手柄和一个圆手柄。
- [ ] 在框内拖动移动对象，光标变成四向箭头。
- [ ] 拖角手柄缩放，对角保持不动。
- [ ] 拖边手柄只改变一个方向。
- [ ] 拖角时按 **Shift** 保持比例。
- [ ] 拖圆手柄绕对象中心旋转。
- [ ] 旋转时按 **Shift** 吸附到 15° 步进。
- [ ] 翻转按钮镜像对象。
- [ ] 框跟着对象旋转，手柄沿对象自己的方向工作。
- [ ] 点击框外把对象落到图层上。
- [ ] **Esc** 丢弃对象。
- [ ] 落下对象是一步撤销。

## 重新拾起曲线

- [ ] 工具选项栏的按钮和 **Ctrl + E** 能拾起最近提交的曲线。
- [ ] 编辑时曲线从图层上取下，编辑完成后重新画上。
- [ ] **Esc** 把旧曲线放回去。
- [ ] **Ctrl + C** 把最近提交的曲线作为图像复制到剪贴板。
- [ ] 没有曲线时，**Ctrl + C** 照常复制图层。

## 容易出错的地方

- [ ] 曲线提交后画布上不留下任何东西：没有框、没有标记、没有预览。
- [ ] 很大的图像（3000×2000 以上）拖动时仍然跟手。
- [ ] 100% 和高倍缩放下的结果一致。
- [ ] 两点曲线看起来和 Pinta 自带 *Line/Curve* 工具画的线一样。
- [ ] 撤销和重做一次一条曲线，不会把两条曲线合并成一步。
- [ ] 工具不干扰 Pinta 自带的工具；卸载插件后 Pinta 自带工具仍然正常。
- [ ] 状态栏提示随状态变化：空闲、放点、调整已完成的曲线。

## 外观

- [ ] 工具图标在浅色和深色主题下都清晰。
- [ ] 标记和框在浅色和深色图像上都看得见。
- [ ] 工具选项栏和样式面板在两种主题下都正常。
